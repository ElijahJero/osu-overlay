Add it to OBS

  1. Copy the link above. Standard has no extra path. Taiko, catch, and mania add one, such as .
  2. Add a Browser source. Paste the link, set the size to 1920×1080, and leave Local file unchecked. Uncheck “Shutdown source when not visible” so the overlay stays connected when you change scenes.
  3. Leave tosu running if you want the map. Rank and scores update on their own. The map panel is optional.

tosu stays on your PC

The live map is not fetched by this website. tosu runs next to osu! and listens on this computer at 127.0.0.1:24050. An OBS browser source is allowed to open that local connection, including when this page is served over https.

A normal browser tab is not. Firefox and Chrome block an https page from talking to tosu, so opening the link yourself shows rank and scores only. Play a map with the OBS source active and the map panel shows up in the corner.
